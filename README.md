# OrderFlow Terminal для Android

Android-версия [OrderFlow Terminal](https://github.com/Hxck3r/orderflow): футпринт и ордерфлоу-индикаторы по биткоину на телефоне (целевое устройство — Galaxy S25 Ultra). Ядро и график берутся из ПК-версии как есть (git-подмодуль на закреплённом коммите); сам ПК-репозиторий не меняется.

План работ — [docs/ANDROID_PLAN.md](docs/ANDROID_PLAN.md).
